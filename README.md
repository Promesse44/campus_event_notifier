# Campus Event Notifier

**Tagline:** Stay informed. Never miss a campus event.

## Project Overview

Campus Event Notifier is a student-focused application that helps students discover upcoming campus events and keep track of activities happening at their university.

## Problem Statement

Students may miss important campus events because information is shared across different communication channels. This project aims to make event information easier to find and organize in one place.

## Target Users

- University students
- Student clubs and associations
- Campus event organizers

## Core Features

1. **View Events:** Display a list of upcoming campus events.
2. **Event Details:** Show each event's title, date, time, location, and description.
3. **Search and Filter:** Help students find events by name, date, or category.
4. **Create Events:** Allow authorized organizers to add new events.
5. **Event Reminders:** Provide a way for students to keep track of events they are interested in.
